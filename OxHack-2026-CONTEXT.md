# OxHack 26: event context (rules, judging, prizes, schedule)

*Checked 2026-10-24 against Devpost, the MLH event page, the opening-ceremony slides and the organisers' Discord. Sat times are BST (UTC+1); Sun times are GMT (UTC+0): the clocks go back at 02:00 on Sun 25 Oct. Log any data in UTC.*
*Unknowns are marked **unpublished**. Never fill them with a guess; ask (§6).*

## 2. Submission and eligibility

- Submit on Devpost and give a GitHub link (the official rule, in full). No video requirement is published; the form asks which AI tools you used (disclose honestly).
- Teams of up to 4. UK university students aged 18+ (or within a year of graduating).
- **Unpublished:** pre-existing code or data rules; how many prizes one project can enter or win; rewards for First, Runner Up, Handmade, HRT and Delta. MLH's default rules (code written during the event, public repo, libraries and open source allowed, AI tools allowed if disclosed) are the only written guide, and OxHack hasn't said it adopts them. Keep the repo public and do the work on the day.

## 4. Judging format

Science fair: each judge gives **4–5 minutes** and we choose the format. Plan a demo-first walkthrough of about 4 minutes, repeated for each judge, with the decision beating the baseline shown in the first minute. Someone must be at the table for the whole 13:00–15:45 window.

## 5. Hardware (for a handmade piece)

The MLH Hardware Lab (collect from the MLH table) lists **Raspberry Pi Pico/RP2040**, Grove servo, LEDs, rotary angle sensor, LCD, 7-segment display, motor/servo driver, jumper wires, breadboards and basic tools. **Stock at this event is unconfirmed**, and no full Linux Raspberry Pi or Wi-Fi Pico is listed. Plan to drive it from a laptop over USB serial.
